# Task1 本地LLM辅助判定人工复核

## 1. 复核范围

- 样本来源：`/tmp/structured_rules_llm.csv`
- 复核对象：所有 `classification_evidence` 中包含 `llm_backend=ollama` 的结构化事件
- 总样本数：`15`

复核目标：
- 判断本地 LLM 介入后，结果是“明显变好 / 基本可接受 / 存在明显风险”
- 为下一轮规则收紧提供人工依据

## 2. 复核结论摘要

- 明显变好：`8`
- 基本可接受：`4`
- 存在明显风险：`3`

总体判断：
- 本地 LLM 对“事件命名压缩”“科技政策类样本行业修正”“边界样本补入结构化事件”有明显帮助
- 当前主要风险集中在：
  - 地缘/外交文本被弱化成政策/宏观口径
  - 宏观/行业数据类文本被打回 `industry_type=其他`
  - 一部分“措施/方案”类文本被过度泛化

## 3. 明显变好的样本

1. `人工智能伦理审查办法发布`
- 复核：明显变好
- 原因：事件名更标准，`政策类 / 科技` 合理，`利好` 也比原来的中性更贴近产业扶持/规范预期

2. `服务消费政策出台`
- 复核：明显变好
- 原因：事件名更标准，`政策类 / 消费` 合理，属于可直接下游使用的标准事件口径

3. `科技赋能春耕生产`
- 复核：明显变好
- 原因：规则版未入结构化，LLM 将其补为 `行业类 / 科技`，符合“科技应用扩散”的金融事件候选

4. `物联网产业创新发展方案发布`
- 复核：明显变好
- 原因：规则版未入结构化，LLM 将行业从误判的消费修正为科技，提升明显

5. `具身智能行业标准发布`
- 复核：明显变好
- 原因：从 `行业类 / 其他 / 中性` 修正为 `政策类 / 科技 / 利好`，更接近产业政策与标准发布的真实语义

6. `春日经济带动文旅消费`
- 复核：明显变好
- 原因：规则版未入结构化，LLM 补入 `宏观类 / 消费`，可作为消费景气类事件候选

7. `无线电频率收费政策调整`
- 复核：明显变好
- 原因：从 `其他 / 中性` 修到 `科技 / 利好`，对通信、卫星、无线电相关产业的金融意义更强

8. `信用信息目录发布`
- 复核：明显变好
- 原因：事件名更适合标准事件表，作为全市场信用治理类政策事件是成立的

## 4. 基本可接受的样本

1. `企业信用评价体系建立`
- 复核：基本可接受
- 原因：`政策类 / 其他 / 利好` 基本说得通，但行业仍偏泛

2. `创新药审批与授权交易增长`
- 复核：基本可接受
- 原因：能补成事件是正向的，但更合适的行业应该偏医药，而不是 `其他`

3. `智能航运2030行动计划发布`
- 复核：基本可接受
- 原因：事件名更标准，但行业从科技改成 `其他` 不够理想，建议保留“航运科技/智能交通”锚点

4. `清明假期出行预测`
- 复核：基本可接受
- 原因：作为宏观消费活动类事件可成立，但规则版把它错误打到新能源，LLM虽然修正了主体方向，却没能给出更好的行业归类

## 5. 存在明显风险的样本

1. `中欧外交通话`
- 复核：存在明显风险
- 原因：规则版是 `地缘类`，LLM 改成 `政策类`，削弱了中东/霍尔木兹/战事等强地缘信号
- 结论：地缘/外交类文本必须保留更强规则锚点，LLM 不应轻易降级

2. `轻工业增加值增长`
- 复核：存在明显风险
- 原因：从 `行业类 / 消费` 被改到 `宏观类 / 其他`，主体与行业都被弱化
- 结论：行业景气数据类文本不应被默认打回 `其他`

3. `轻工业经济运行稳健`
- 复核：存在明显风险
- 原因：从 `政策类 / 消费` 改到 `宏观类 / 其他`，行业锚点丢失
- 结论：轻工业、消费、零售等显式行业词应强约束 `industry_type`

## 6. 下一轮规则优化建议

1. 地缘/外交样本加硬锚点
- 命中 `中东 / 霍尔木兹 / 战事 / 停火 / 冲突 / 空战` 时，优先保留 `地缘类`

2. 行业景气/统计类文本加行业锚点
- 命中 `轻工业 / 零售 / 餐饮 / 文旅 / 医药 / 创新药` 时，不允许 LLM 轻易打回 `其他`

3. `industry_type=其他` 的 LLM 修正需要二次约束
- 若规则已有明确行业词，而 LLM 仍输出 `其他`，优先保留规则行业

4. LLM 当前最适合保留的职责
- 标准事件命名
- 边界样本补入
- 科技政策类样本行业修正
- 摘要压缩与解释增强

## 7. 当前执行建议

- 保持 `规则优先 + 本地 LLM 辅助`
- 对地缘/外交类样本先收紧，再做下一轮对比
- 对 `industry_type=其他` 做专项抽样复核，不要直接把 LLM 结果全量放行

## 8. 收紧后复测结论（2026-04-10）

- 已落地地缘与行业锚点后置修正
- 复测结果：
  - `中欧外交通话`：稳定为 `地缘类 / 其他 / 中性`
  - `轻工业增加值增长`：稳定为 `宏观类 / 消费 / 利好`
  - `轻工业经济运行稳健`：稳定为 `宏观类 / 消费 / 利好`
- 对比口径中 `industry_type=其他` 从 `49` 降到 `48`

结论：
- 本轮收紧方向有效，已覆盖上一轮人工复核中的核心风险点
- 下一轮可继续聚焦：医药类与外交类交叉文本的行业/主体稳定性
