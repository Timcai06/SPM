## 3. 当前系统结构理解

项目现在可以分成三层：

1. 事件层
- `raw_documents`
- `event_candidates`
- `structured_events`

2. 关联层
- `companies`
- `event_company_links`

3. 传播层
- `company_relations`
- `event_propagation_links`

这三层已经形成清晰主线：

`文本 -> 事件 -> 公司 -> 传播`

这说明当前系统架构已经从“单任务脚本集合”升级成了“连续任务链”。
