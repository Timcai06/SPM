# 系统优化路线图

- 时间：2026-04-03
- 目标：在不偏离任务1到任务3主线的前提下，优先提升系统可信度、可解释性和可复现性，为后续数学模型训练打基础

## 1. 总体判断

当前系统已经具备三层能力：

- 任务1：文本到结构化事件
- 任务2：事件到公司
- 任务3：公司关系与一跳传播

现在最合理的策略不是马上上最终预测模型，而是先做“系统优化”。  
因为现在决定模型上限的，不是模型结构，而是输入质量。

当前最关键的四个维度是：

1. `is_event` 判定
2. 事件研究法基础分析
3. 任务2主数据与行业标签
4. 一套成熟的图谱系统

## 2. 优先级排序

建议按下面的顺序推进：

### P0：`is_event` 判定优化

原因：

- 这是任务1的入口阀门
- 一旦这里混入低价值文本，任务2和任务3会被一起污染
- 这是当前影响全系统质量的第一优先级

目标：

- 让“金融事件”与“普通资讯/宣传/模板公告”边界更清晰
- 让 `evidence` 字段更适合人工复核和答辩展示

具体工作：

1. 扩人工复核样本到 20-50 条
2. 建误判/漏判样本池
3. 继续收紧以下边界：
   - 泛宏观评论
   - 官媒叙事类报道
   - 普通公告模板
   - 无明确市场冲击的例行信息
4. 把 `evidence` 输出规范化

验收标准：

- 人工可读地解释为什么判成事件/非事件
- 误判类型能被归类
- 规则版本升级后能稳定复跑

### P1：任务1人工质量闭环

原因：

- 当前系统“能跑”已经成立
- 但还缺“人工复核口径”来支撑答辩

目标：

- 形成任务1可答辩的质量指标

具体工作：

1. 完成 `quality_sample.csv` 人工标注
2. 重跑质量报告
3. 输出以下指标：
   - 识别准确率
   - 四维标签一致率
   - 字段完整率
   - Top误判原因

验收标准：

- 任务1不再只是工程演示，而是有质量闭环

### P2：事件研究法基础分析增强

原因：

- 这部分现在已能跑，但样本量和稳定性还不够强
- 它是“任务1到建模”的中间桥梁

目标：

- 提高统计结果可信度
- 固定分析口径，便于批次对比

具体工作：

1. 增加高质量事件样本
2. 增加高质量事件-公司链接
3. 固定分析配置：
   - 估计窗
   - 事件窗
   - 基准
4. 跟踪不可计算样本原因

验收标准：

- CAR 报告可稳定复跑
- 分组统计样本足够
- 不可计算样本原因清晰

### P3：任务2主数据与行业标签增强

原因：

- 任务2当前瓶颈主要不是算法，而是主数据质量
- `industry_match` 的上限被 `companies` 质量卡住了

目标：

- 提升事件-公司关联的覆盖率和可信度

具体工作：

1. 扩 `companies`
2. 补行业一级/二级标签
3. 持续维护 `companies_manual.csv`
4. 区分：
   - 明确直连
   - 行业联动
   - 候选弱关联

验收标准：

- 任务2覆盖率提升
- 高分链接更可信
- 误关联样本减少

### P4：任务3图谱系统成熟化

原因：

- 任务3底座已经有了
- 现在真正缺的是“高质量边”，不是更复杂的图数据库产品

目标：

- 把任务3从“图传播 demo”推进到“可解释图谱系统”

具体工作：

1. 扩充 `company_relations_seed.csv`
2. 做关系边人工复核
3. 按链路分层补边：
   - 军工链
   - 新能源/储能链
   - AI/机器人链
   - 金融链
   - 消费出行链
4. 维持一跳传播，不急着上多跳
5. 保持 `propagation_path` 可解释

验收标准：

- 传播样本有行业逻辑
- 传播路径能讲清楚
- 无向边、重复边、脏边可控

## 3. 为什么现在不先做最终预测模型

当前还不建议直接把重心转到最终预测模型，原因有三点：

1. 任务1准确率还没做完人工闭环
2. 任务2覆盖率偏低
3. 任务3关系边仍在持续完善

这意味着：

- 现在可以做“验证型建模”
- 但还不适合把重点放在“最终预测效果”

更合适的节奏是：

1. 先优化系统输入
2. 再做解释型/验证型模型
3. 最后再做正式预测模型

## 4. 当前推荐推进顺序

接下来建议按这条线推进：

1. 任务1人工复核
2. `is_event` 再精修一轮
3. 扩 `companies` 和行业标签
4. 扩 `company_relations_seed.csv`
5. 重跑任务2、任务3质量抽样
6. 再开始第一轮数学模型训练

## 5. 一句话结论

现在系统的最优策略不是“再堆模型”，而是“把输入层、关联层、传播层的质量一起抬高”。  
等这三层更稳之后，后面的数学模型训练才会更像真正的研究，而不是拿噪声去拟合噪声。
