# Governance 文档组

这里放的是“系统有什么约束、踩过什么坑、下一步优先做什么”的文档。

## 包含内容

| 文档 | 作用 |
|---|---|
| [known-issues.md](known-issues.md) | 实际遇到过的问题、根因和当前解决方式 |
| [storage-retention-policy.md](storage-retention-policy.md) | 空间热点、可删数据、长期保留原则 |
| [engineering-roadmap.md](engineering-roadmap.md) | 当前 P0/P1/P2 工程路线和 backlog |

## 适合什么时候看

- 你准备做工程优化
- 你想知道哪些问题已经解决，哪些还没解决
- 你想决定下一步资源该投在哪
